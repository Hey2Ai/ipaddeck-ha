# iPadDeck für Home Assistant

Home-Assistant-App (Add-on) mit einem iPad-Kiosk-Dashboard: Räume, Haushaltsgeräte, Einkaufsliste,
Wetter, Szenen. Die Oberfläche ist reines ES5 und läuft auch auf alten iPads (iOS 9+).

Installation: In Home Assistant unter Einstellungen → Apps → App-Store → ⋮ → Repositories diese URL hinzufügen,
dann „iPadDeck Wohnzimmer“ installieren und starten.
